# 📈 Online Sales Analysis

A Python project that manages products and a customer shopping cart using object-oriented programming.

## 📒 Classes

- `Product`: *stores a product's name, price, and quantity.*
- `ProductManager`: *adds, displays, removes, and calculates the value of products.*
- `Cart`: *stores selected products, displays the cart, and calculates the total.*

## 🐍 Run

```bash
python3 main.py
```
